# 🗄️ AWS RDS Essentials 

Welcome to my **AWS RDS (Relational Database Service)** learning journey!
This repository documents my progress through the **AWS RDS Course** on KodeKloud — teaching everything from why databases matter, to multi-AZ architecture, backups, security, and Aurora.

Each lab will be documented in its own folder with a README containing:

✅ Step-by-step commands
🐛 Troubleshooting notes
💡 Key takeaways

---

## 📘 Course Summary

By completing this course, I’ll gain in-depth experience with:

* 🗄️ **Database fundamentals**: why we need databases & what problems they solve
* 📦 **RDS basics**: managed databases, benefits, console overview
* 🧪 **Hands-on labs**: creating MariaDB/Postgres instances, connecting apps
* 🧱 **RDS architecture**: instance types, storage types, read replicas, cross-region DR
* 🚀 **Scaling models**: Single-AZ, Multi-AZ, Multi-AZ cluster, Blue/Green deploys
* 🔐 **Networking & security**: authentication, Secrets Manager, security groups, RDS Proxy
* 💾 **Backup & restore**: automated backups, snapshots, point-in-time recovery
* ⚡ **Aurora**: architecture, benefits, pricing, serverless v2
* 📊 **Monitoring**: Performance Insights, CloudWatch logs/metrics, query tools
